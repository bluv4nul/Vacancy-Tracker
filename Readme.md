# Vacancy Tracker

> В разработке

Веб-приложение для поиска стажировок и вакансий разработчика и учёта откликов.

Стажировки и вакансии разбросаны по hh.ru, сайтам крупных компаний и каналам в соцсетях. Vacancy Tracker собирает их в одном месте: вакансии с hh.ru подтягиваются автоматически по сохранённым поискам, остальные добавляются вручную. Внутри — исключение по словам, скрытие компаний, статусы откликов и уведомления о новых вакансиях в Telegram.

## Возможности (MVP)

- Сохранённые поиски по hh.ru с фоновой проверкой новых вакансий
- Поиск по словам: режим «все слова» / «любое слово» и слова-исключения
- Лента новых непросмотренных вакансий без дублей
- Ручное добавление вакансий из других источников
- Статусы откликов: интересно → откликнулся → тестовое → собес → оффер / отказ
- Скрытие компаний и заметки по вакансиям
- Уведомления в Telegram

## Стек

- JavaScript, Node.js, Express
- PostgreSQL (драйвер `pg`, сырой SQL)
